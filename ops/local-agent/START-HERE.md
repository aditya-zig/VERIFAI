# Start here

1. Read `CURRENT-STATE.md`.
2. Run `scripts/preflight.sh`.
3. Open your assigned GitHub issue and verify it is still canonical.
4. Checkout/create the issue branch.
5. Run the existing baseline test for that issue.
6. Implement only that issue.
7. Verify manually in the browser when UI behavior changes.
8. Push and create/update the PR. Do not auto-merge.
9. Finish with `HANDOFF-TEMPLATE.md`.

> Never implement from memory or an old chat. GitHub + Notion + the current checkout are the source of truth.
