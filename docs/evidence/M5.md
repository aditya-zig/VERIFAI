## Safety and recovery

1 GiB RAM, 2 CPUs, nonprivileged/non-root, network none, caps dropped,
no-new-privileges, pids 64, bounded tmpfs; no host mounts/socket/model credentials.
Actual limits are inspected. Clone copy uses a disposable writable layer,
explicitly not a read-only rootfs. Only M3's three narrow command policies run.

Command 10 s, model 60 s, clone 119 s, total master 120 s; cancellation and bounded
output (8 KiB/stream). Errors/capability gaps and failed master checks are
Incomplete with failed stage named. Docker exit 1 remains a real Failed execution
inside that Incomplete master result. Cleanup failures cannot return Completed.

Workspace ownership is persisted before mkdir beneath the checkout-owned state
root. SIGTERM/SIGINT cancel and clean; dead PID/start-identity clone registrations
and labelled sandbox containers recover on restart. Live owners are preserved;
unverified ownership is refused. Actual tests cover success, SyntaxError failure,
started-command timeout, Busy, abort, real HTTP interruption, unavailable model,
SIGKILL owner recovery, and different-state-root live-container preservation.
