## Safety and resources

One command audit at a time (429 Busy otherwise); one model call after actual
execution. No arbitrary shell or model-supplied executable text. Scripts are
compiled only when exactly `node --version` or `node --check <tracked file>`;
never run npm/yarn/pnpm hooks, package installs, .npmrc or script-shell. Detect
lockfile manager for provenance. Fallback is an explicitly allowed tracked README
check. Child environment contains no API key/token/secret and no NODE_OPTIONS.

Default command timeout 10 s, strictly below 120 s; SIGKILL targets the owned
process group. Output is capped at 8 KiB per stream (tail). Timeout becomes
Incomplete; nonzero command exit is Failed; missing command or failed analysis
is Incomplete, never Verified. Model cannot replace captured execution fields.

Web Node RSS observed about 85 MiB; npm launcher about 72 MiB. Machine had
about 2.2 GiB available RAM after the check. No Docker work performed in M3.

## Limitations

Only the above narrow read-only command policy is implemented. Most existing
project test/lint/typecheck scripts are intentionally unsupported; a README check
is not a substitute for them. M3 runs on the host, not Docker. Clone cleanup is
explicit through the UI (M4/M5 still need sandbox and full lifecycle integration).
M2 `/analyze` remains available, independently tested. No mocked model or command
output in M3 acceptance; the local package.json is a fixture input, not evidence
fabrication. M4 and M5 are not proven by these checks.

Safe stop: `./ops/local-agent/scripts/stop-local.sh` from the canonical checkout.
