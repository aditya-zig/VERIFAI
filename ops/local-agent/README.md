# VERIFAI local-agent kit

A small operating guide for fresh coding agents working on the local-first VERIFAI roadmap.

Start with [`START-HERE.md`](START-HERE.md).

| File | Purpose |
| --- | --- |
| `CURRENT-STATE.md` | roadmap and current blockers |
| `AGENT-RULES.md` | non-negotiable execution rules |
| `SETUP.md` | machine/repo setup |
| `ENVIRONMENT.md` | current vs deferred env vars |
| `DOCKER.md` | M4+ Docker guidance |
| `TROUBLESHOOTING.md` | bounded diagnosis |
| `WORKFLOW.md` | issue -> evidence -> PR loop |
| `VERIFY.md` | verification path |
| `HANDOFF-TEMPLATE.md` | required final handoff |
| `env/local.env.example` | placeholders only |
| `scripts/` | safe preflight, doctor, lifecycle and verification helpers |

Core rule: GitHub + Notion + the current checkout outrank memory and old chats.
