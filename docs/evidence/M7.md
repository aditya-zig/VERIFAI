# M7 — one real local fixture browser journey (#13)

PR: https://github.com/aditya-zig/VERIFAI/pull/59. Stacked on M6; human merge only.

## Defined journey

Defined before code in https://github.com/aditya-zig/VERIFAI/issues/13#issuecomment-5925569619:
start a tiny loopback fixture → open installed isolated headless Chrome → click its single button → assert visible `Action completed` → capture actual screenshot, URL, console/network and timing → close Chrome/profile/fixture.

This is explicitly **integration proof of a fixture**, NOT browser verification of an arbitrary cloned application. No general URL, action, crawl, video, cloud or desktop input. One browser, on demand; it shares M5 admission so a simultaneous model/Docker audit returns 429 Busy.

## Implemented

- `services/local-browser.mjs`: ephemeral profile, credential-free Chrome environment, bounded abort/CDP/shutdown, actual assertion and PNG, bounded evidence, 30 retained <=1 MiB screenshots, truthful failure cleanup.
- POST `/api/local/audits/:id/browser` requires an existing Completed M5 run. GET associated evidence and screenshot. Exact recorded identity only, bounded binary proxy and no-follow owned-file reads; no arbitrary path access.
- Real UI shows `Run fixture browser journey` only after Completed M5, its explicit fixture disclaimer, result, cleanup and actual screenshot link.
- Local starter retains provider credentials in API only, not proxy/web children. This concrete leak was reproduced using a controlled sentinel (never a real key) and repaired.
